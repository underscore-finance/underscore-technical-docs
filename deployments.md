# Deployed Contracts

Params Explorer is the live onchain reference for Underscore Protocol on Base. Use it to inspect current protocol parameters, vault configurations, approved Lego integrations, and deployed contract addresses.

For deployment-specific addresses, go to:

**[https://params.underscore.finance/deployments](https://params.underscore.finance/deployments)**

This page contains the current addresses for all Underscore Protocol contracts on Base Mainnet, including:

- User Wallet contracts
- Wallet Backpack components
- Core infrastructure
- Yield and DEX Legos
- Data contracts
- Agent contracts
- Registries
- Configuration contracts
- Earn Vaults
- Leverage Vaults
